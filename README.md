# Portfolio Website

A responsive, lightweight personal portfolio website built to showcase software engineering experience, technical skills, projects, and professional background.

## Features & UI Elements

* **Hero Section:** Personal intro with call-to-action buttons for resume viewing/download and quick contact links.
* **About Section:** Overview of engineering background, career goals, and professional summary.
* **Experience & Projects:** Detailed breakdown of past roles, responsibilities, and featured projects with links to source repositories.
* **Skills Showcase:** Categorized technical skill sets covering languages, web tools, and frameworks.
* **Interactive Scripts:** Client-side JavaScript handling dynamic interactions, navigation, and visual features.
* **Fully Responsive Design:** Custom CSS styling optimized across desktop, tablet, and mobile viewports.

## Tech Stack

| Technology | Role |
| :--- | :--- |
| **HTML5** | Semantic structure and accessibility markup |
| **CSS3** | Custom layout, styling, and responsive media queries |
| **JavaScript (ES6+)** | Dynamic UI interactions and client-side logic |
